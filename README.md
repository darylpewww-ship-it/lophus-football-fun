# Lophus Football Fun

A football manager game with a fantasy twist that runs in the browser. You are the manager: hire the coach, sign players, raise your club's gem, fuse skills in the Lab, upgrade the stadium and fill the trophy cabinet. Every club, player, crest and skill is generated for your world.

Play: https://darylpewww-ship-it.github.io/lophus-football-fun/

Files: `core.js` (world, simulation, time, transfers), `live.js` (2D match engine), `ui.js` (pages), `enc.js` (encyclopedia), `actions.js` (buttons and boot).
